# Changelog

All notable changes to this project will be documented in this file.

## [1.2.0] - 2026-11-06

### Fixed

- Fixed compatibility with the latest LibCharacterKnowledge - the addon shows
  motif/recipe price again after its update.
- Price label no longer overlaps other tooltip text.

## [1.1.1] - 2023-05-21

### Changed

- Updated addon metadata.

## [1.1.0] - 2023-05-21

### Fixed

- Price label no longer shows up when hovering over items other than master
  writs.

## [1.0.0] - 2023-04-30

### Added

- Initial release: show recipe or motif price (TTC / MasterMerchant /
  ArkadiusTradeTools) for a master writ in tooltips for bag, bank and guild
  store items.
